# 历史状态与板块成分来源核验

**核验日期**：2026-10-27
**本地依赖版本**：AkShare 1.19.3
**对应任务**：P03
**结论**：当前依赖中没有已验证、可直接覆盖回测区间的历史 ST、停牌、退市和板块成分日快照。依赖缺口会阻塞正式信号/回测，但不阻塞 actual TXT 解析、原始保存和基础行情入库。

## 1. 已检查的接口能力

| 输入 | 候选来源/接口 | 可确认能力 | 历史覆盖结论 | 当前处理 |
| --- | --- | --- | --- | --- |
| ST 状态 | AkShare `stock_zh_a_st_em` | 风险警示板股票列表及当前行情字段 | 接口无交易日参数；源码返回当前风险警示板，不能据此生成 T 日历史 ST 快照 | 不作为历史状态来源 |
| 停牌状态 | AkShare `stock_tfp_em(date=...)` | 可按日期查询两市停复牌数据 | 接口有日期参数；尚未取得带字段定义、历史覆盖起止日和修订规则的可审计导出样例 | 可作为候选来源；接入前必须逐日核对 |
| 退市状态 | AkShare `stock_zh_a_stop_em` / 交易所公告 | 两网及退市列表或公告信息 | 当前列表不能还原每个交易日的退市状态和最后交易日 | 不用当前列表回填历史；模型增加 `is_delisted` 字段 |
| 行业板块成分 | AkShare `stock_board_industry_cons_em` | 指定板块的成分股列表 | 接口无交易日参数，返回当前成分；不能直接生成历史成分快照 | 不作为历史成分来源 |
| 板块指数日线 | AkShare `stock_board_industry_hist_em` | 指定板块的历史行情，可按日期范围查询 | 可支持 `sector_daily` 的历史指数，但不提供同日历史成分 | 可作为板块日线候选来源，待字段/覆盖抽查 |
| 上证指数/市场状态 | AkShare `stock_zh_index_daily_em(symbol=..., start_date=..., end_date=...)` | 指定指数和日期范围的历史日线 | 可作为 `market_daily.sh_close` 候选来源；指数代码、交易日完整性和 MA20 计算仍需固定 | 可作为市场日线候选来源，待字段/覆盖抽查 |
| 全市场涨停数 | AkShare `stock_zt_pool_em(date=...)` | 指定交易日的涨停股池 | 可按日取得涨停池，再按项目股票范围和历史状态口径计数；尚未核验停牌/ST/特殊板块处理 | 可作为候选来源，待口径测试 |
| A 股历史行情 | AkShare `stock_zh_a_hist` | 指定证券、日期范围和复权类型的日线 | 仅覆盖价格/成交等行情字段，不提供历史 ST、停牌或板块成分 | 不替代历史状态表 |

上述判断基于 AKShare 官方仓库当前接口清单和对应源码；本次只核验接口声明/源码，不调用外部网络写入数据库，也没有把接口存在等同于数据覆盖已验收。

## 2. 必须取得的可审计字段

正式接入前，每个来源至少要记录：

- 来源名称、接口或文件版本、抓取时间和原始文件校验和；
- 交易日字段及其时区/日期口径；
- 证券代码、名称、`is_st`、`is_suspended`、`is_delisted`；
- 停复牌的状态语义（全天停牌、临时停牌、复牌日如何编码）；
- 退市生效日、最后交易日或可等价推导这些字段的原始记录；
- 板块代码、板块名称、证券代码和成分有效日期；
- 覆盖起止日、缺失交易日、重复记录和修订规则。

没有这些元数据时，清单只能标记为 `partial` 或 `invalid`，不能作为正式回测输入。

## 3. 当前缺口与解除条件

1. **历史 ST**：需要逐交易日风险警示状态快照，或可审计的状态变更记录；当前列表接口不足。
2. **历史停牌**：需要逐代码逐交易日的停牌状态和临时停牌语义；仅有当前停牌列表不足。
3. **历史退市**：需要退市生效日/最后交易日，并保留退市前的历史行情和股票池记录。
4. **历史板块成分**：需要按交易日保存成分，而不是用当前成分回看历史；当前成分接口不足。
5. **覆盖年限**：在取得原始导出后，逐表生成最小日期、最大日期、交易日覆盖率、代码覆盖数和缺口清单；当前未生成覆盖数字。

在上述资料到位前，`stock_status_daily`、`sector_membership_daily` 只能接受明确标注来源和状态的输入；测试夹具仅用于验证时点查询语义，不代表真实数据。
