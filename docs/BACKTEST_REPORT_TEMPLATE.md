# BACKTEST_REPORT_TEMPLATE

**项目**：stocktool
**版本**：v1.0 / 2026-10-23

## 1. 指标表

| 字段 | 说明 |
| --- | --- |
| run_id | 回测 ID |
| 起止日期 | |
| 样本 | in / out |
| 信号数 / 成交数 | 未成交含 T+1 涨停 |
| 胜率 | 盈利笔/成交笔 |
| **盈亏比** | 平均盈利/平均亏损（主指标） |
| 期望值% | 每笔平均收益（扣成本） |
| 最大回撤% | 资金曲线 |
| 夏普 | 日频年化（可选） |
| 平均持有天数 | |
| 连续亏损最大笔数 | |
| 参数快照 | JSON |
| 敏感性表 | 回调幅度/缩量比/均线周期各 ±20% 结果 |

## 2. 判读规则

- 盈亏比 ≥1.5 且期望 >0 为可用；
- 样本外盈亏比 ≥ 样本内 70%；
- 敏感性扰动后指标不崩（盈亏比波动 <30%）。
