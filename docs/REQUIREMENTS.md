# REQUIREMENTS

**项目**：stocktool
**版本**：v1.1 / 2026-10-24

## 1. 功能需求

| ID | 需求 | 验收要点 |
| --- | --- | --- |
| FR1 | 通达信 TXT 解析入库 | 附件格式可解析；代码补零映射；单位统一（量=股，额=元） |
| FR2 | 复权统一 | 使用可验证因子转前复权；qfq 价格绑定不可变 `price_snapshot_id` |
| FR3 | AkShare 增量补数 | 板块日线、历史板块成分、市值/流通/换手、涨停池和市场状态 |
| FR4 | 按年分区 | `daily_price`/`stock_status_daily`/`stock_extra` RANGE 分区，每年一分区+默认分区 |
| FR5 | 股票池过滤 | ST/上市60日/停牌/流动性1亿/市值30亿/换手1% |
| FR6 | 主线板块 | 东财板块5日涨幅前8、涨停≥2、站上20日线 |
| FR7 | 异动标记 | 10 日内涨停或放量异动 |
| FR8 | 买入信号 | 6 条件全满足；输出区间/止损/评分/仓位 |
| FR9 | 评分体系 | 五因子加权 0—100，A/B/C 分级 |
| FR10 | 回测 | T+1 开盘买、规则卖、成本 0.1%、指标齐全 |
| FR11 | Streamlit 展示 | 当日信号表 + 回测摘要 |
| FR12 | start/close 脚本 | 一键启停 API+Web |
| FR13 | 历史时点数据 | 保存 T 日 ST、停牌、退市状态和板块成分，回测不得使用当前状态回看历史 |
| FR14 | 数据版本追溯 | qfq 价格、输入清单、参数快照可关联到信号和回测结果 |
| FR15 | 可复现回测 | 固定 T+1 开盘买入、日线保守撮合、未成交/延迟成交和成本规则 |

## 2. 非功能需求

- NFR1 每日盘后全流程 ≤5 分钟；
- NFR2 数据校验失败写 `logs/error.log` 并告警；
- NFR3 pytest 覆盖核心计算；
- NFR4 本地 `http://localhost:8501` 访问；
- NFR5 敏感配置走 `.env`，不入 Git。
- NFR6 缺少关键输入时标记 `partial` 并阻止正式验收，不得静默填补。
- NFR7 正式结果可根据 `price_snapshot_id`、`data_manifest_id` 和参数快照复现。

## 3. 范围外

实时行情、盘中推送、自动交易、券商接口、多用户、移动端、对外服务。
