## 1. 使用规则

- `[ ]` 未开始；`[~]` 进行中；`[x]` 已完成；`[!]` 被阻塞。
- 按依赖顺序推进；前置验收未通过，不进入依赖任务。
- 先编写确定性测试和固定样例，再实现对应功能。
- 完成任务后填写状态、验证命令和产物；阻塞时记录原因及解除条件。
- 仅执行项目范围内的个人盘后工具，不扩展到实时行情、自动交易、券商接口或公网服务。

## 2. 阶段总览

| 阶段 | 目标 | 关键出口 |
| --- | --- | --- |
| 0. 开发准备 | 确认运行环境、数据来源与历史数据可得性 | 可验证的样例数据及缺口清单 |
| 1. 数据底座 | 解析、版本化、存储并校验行情及历史状态 | 指定股票可查询完整日线及输入版本 |
| 2. 信号引擎 | 实现股票池、主线、异动、触发、评分和仓位 | 确定性测试通过，CSV 信号可人工复核 |
| 3. 回测 | 实现保守日线撮合、成本、指标及样本隔离 | 可复现报告；数据不完整时拒绝正式结论 |
| 4. 应用与运维 | API、仪表盘、日常脚本和日志 | 本地盘后流程端到端可运行 |
| 5. 验收与跟踪 | 完成历史抽查、连续运行和跟踪准备 | 验收记录及跟踪表 |
