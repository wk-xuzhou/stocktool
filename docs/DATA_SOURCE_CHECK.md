成交量/成交额单位的初步核对仍按原始字段保存：成交量不自动乘 100，成交额不自动换算。以实际文件中的量额为准；若未来出现明确标注为“手”的其他来源，才在解析参数中显式转换。

## 3. P01 结论

P01 的原结论已按实际目录纠正：

- `export_no` = actual/不复权；
- `export_f` = qfq/前复权；
- `export_b` = hfq/后复权；

- 解析器必须识别文件头口径，并保留空数据文件和坏数据的可定位报告。

P01 可以保持完成，但验证产物必须以本记录为准；此前写成 `export/`、且把 `export` 解释为 hfq 的表述作废。
