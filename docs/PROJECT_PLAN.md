
# PROJECT_PLAN

**项目**：stocktool
**版本**：v1.0 / 2026-10-23

## 1. 目标

开发一个个人自用、B/S 架构、盘后运行的 A 股波段选股工具：基于"主线板块内异动股回调确认"策略，每日盘后输出 **0—100 评分 + 建议买入区间 + 建议仓位 + 止损位** 的信号清单，并通过回测验证信号期望值。**不做自动交易，不对外服务。**

## 2. 范围边界

**做**：数据层（通达信TXT + AkShare增量）、信号引擎、回测模块、Streamlit 前端、PostgreSQL 存储、start.sh/close.sh 启停。

**不做**：实时行情、盘中推送、自动交易、券商接口、多用户、UI 美化、移动端。

## 3. 硬约束

| 项 | 约束 |
| --- | --- |
| 开发方式 | Codex 生成代码，个人审代码 |
| 开发投入 | 20 小时，4 周（每周约 5 小时） |
| 操作系统 | macOS（开发+运行）；通达信在另一台 Windows PC |
| Python | 3.12 + venv + Git |
| 数据库 | PostgreSQL，**按年 RANGE 分区**，8 年数据，深A+沪A+创业板，排除 ST |
| 数据源 | 通达信 TXT（OHLCV，后复权导出→入库统一转前复权口径）；AkShare 补板块/市值/换手/涨停校验；**无 Tushare** |
| 股票范围 | 沪深主板+创业板，排除 ST、北交所、科创板、上市不足 60 日 |
| 板块口径 | **AkShare 东财行业+概念板块日线，唯一来源** |
| 持有周期 | **数日**（目标 3—5 个交易日，最长不超过 10 日） |
| 仓位 | 单票 10%—20%，跟踪期总资金 20,000 元 |
| 执行 | 次日开盘买入 或 次日挂限价区间；卖出用条件单 |
| 评估偏好 | **盈亏比优先**（不是高胜率优先） |
| 验收 | 信号准确率（见 TEST_PLAN） |
| 跟踪期 | 2 个月，20,000 元 |

## 5. 风险清单

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| AkShare 接口不稳定/封 IP | 数据断更 | 通达信为主源；重试+缓存；失败跳过补字段 |
| 后复权导出与前复权口径冲突 | 信号价格错乱 | **入库层统一做复权换算**，全库 `adj_type='qfq'`；每周全量覆盖 |
| 分区表主键限制 | 建表失败 | 主键含分区键 `(code, trade_date)` |
| 参数过拟合 | 样本外失效 | ≤6 参数；±20% 扰动；留最后 1 年样本外 |
| 4 周 20 小时低估数据层 | 延期 | W1 只保"能查任意股日线"，校验可后置 |

## 6. 验收标准（同时满足）

1. 回测盈亏比 ≥1.5 且期望值 >0（扣单边 0.1%）；
2. 样本外（最后 1 年）盈亏比 ≥ 样本内 70%；
3. 连续 5 个交易日盘后自动跑通，无人工干预；
4. 人工抽查 20 个信号，逻辑错误 = 0；
5. 2 个月跟踪期计划内交易占比 ≥90%。
